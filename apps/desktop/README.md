# Gwittim Desktop

This app will become the desktop overlay client.

Planned responsibilities:

- Microphone and system-audio permission flow.
- Realtime subtitle overlay.
- Original transcript view.
- Live summary panel.
- Korean-to-English response composer.
- Session review screen.

No runtime stack has been committed yet. Candidate stacks include Electron, Tauri, or a browser-first prototype before desktop packaging.
