# Roadmap

## Phase 0: Foundation

- Create repository structure.
- Define product brief.
- Define realtime event protocol.
- Define privacy and consent requirements.
- Choose first client target: browser prototype or desktop overlay.

## Phase 1: Realtime Interpretation Prototype

- Microphone capture.
- Realtime audio streaming through Gemini Live API WebSocket.
- English transcription events.
- English-to-Korean interpretation events.
- Subtitle-style UI.
- Rolling transcript panel.

## Phase 2: Meeting Assistant

- Live summary.
- Action item extraction.
- Korean-to-English response composer.
- Quick response modes: agree, disagree, question, suggest.

## Phase 3: Desktop Experience

- Desktop overlay window.
- Always-on-top mode.
- Meeting-app-friendly layout.
- System audio support where platform permissions allow it.

## Phase 4: Review and Learning

- Post-session note.
- Useful expression extraction.
- Natural English rewrite suggestions.
- Searchable session history.

## Phase 5: Advanced Modes

- Speaker separation.
- Domain glossaries.
- Interview mode.
- Sales/customer support mode.
- Bilingual conversation mode.
